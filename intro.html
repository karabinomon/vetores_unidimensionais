Vetores (arrays) unidimensionais

Declaração e inicialização de vetores

O que são Vetores?

Vetores (ou arrays) são estruturas lineares que organizam vários dados do mesmo tipo em uma única variável, um após o outro. Em vez de criar várias variáveis, você guarda tudo em sequência, acessando cada valor por sua posição (índice).

notas = [7.5, 8.0, 6.5, 9.0, 7.0]

Passe o mouse sobre os elementos para inspecionar os índices:

7.5
[0]
notas[0] → 7.5
8.0
[1]
notas[1] → 8.0
6.5
[2]
notas[2] → 6.5
9.0
[3]
notas[3] → 9.0
7.0
[4]
notas[4] → 7.0

Atenção: A indexação na maioria das linguagens (incluindo Python) sempre começa em 0.

Por que usar vetores?

Sem Vetor (Variáveis Soltas)

nota1 = 7.5
nota2 = 8.0
nota3 = 6.5
...

Difícil de gerenciar quando o número de itens cresce.

Com Vetor (Array)

notas = [7.5, 8.0, 6.5]

Apenas uma variável. Acesso fácil por índice.

Trabalhando com Listas em Python

Em Python, os vetores são chamados de listas. Criamos uma lista usando colchetes [] e separando os itens por vírgulas.

# Declarando e inicializando a lista
idades = [14, 15, 16]

# Acessando elementos pelo índice
print(idades[0])  # Saída: 14
print(idades[1])  # Saída: 15

Descobrindo o Tamanho (len)

A função len() descobre quantos itens a lista possui.

idades = [14, 15, 16]
print(len(idades)) # Saída: 3

Alterando Valores

Acesse a posição pelo índice e atribua um novo valor com o sinal de igual =.

idades = [10, 25, 32]
idades[0] = 18
print(idades) # Saída: [18, 25, 32]

Erros Comuns

Cuidado ao acessar os índices! Estes são os tropeços mais frequentes de quem está começando:

1. Índice inexistente (Out of Range)

Tentar acessar uma posição que está além do tamanho da lista.

notas = [7.5, 8.0, 6.5] # Índices válidos: 0, 1 e 2
print(notas[3]) 
IndexError: list index out of range

2. Confundir ordem com índice

Querer acessar o primeiro elemento e usar o número 1.

notas = [7.5, 8.0, 6.5]
print(notas[1]) # Retorna 8.0 (este é o SEGUNDO elemento!)
print(notas[0]) # Forma correta de pegar o PRIMEIRO: 7.5

A Regra de Ouro

Um vetor com N elementos possui índices que vão de 0 até N-1.

Prática

Você está iniciando o desenvolvimento de um pequeno sistema. Crie um programa em Python que:

  1. Declare e inicialize um vetor para armazenar cinco números inteiros (ex: notas, idades ou quantidades).
  2. Mostre na tela (usando print) cada valor armazenado e sua respectiva posição (índice).
Dica: Lembre-se que o primeiro valor deve ser acessado no índice [0].

  • 2. Compreendemos que o acesso aos elementos é feito por índices que começam em zero, exigindo atenção para evitar o erro de Out of Range.
